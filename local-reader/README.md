# 헤번레 스타일 읽기 (Windows)

스타일 목록 스크린샷에서 스타일, 한계 돌파 수, 다프네 여부를 읽는 로컬 프로그램입니다. 분석 중 네트워크나 AI API를 사용하지 않습니다. 부대 편성과 서포트 화면은 지원하지 않습니다.

## 실행

배포 폴더의 `HBRStyleReader.exe`를 실행하세요. `_internal` 폴더를 포함한 전체 폴더가 필요합니다. Python 설치는 필요 없습니다.

소스에서 실행할 때는 Python 3.11 이상과 Tkinter가 필요합니다. 처음에 `powershell -ExecutionPolicy Bypass -File setup.ps1`로 의존성을 설치한 다음 `start-reader.cmd`를 실행합니다. 최초 설치에는 인터넷이 필요합니다.

## 사용

1. **사진 추가**로 스타일 목록 스크린샷 여러 장을 선택하거나 **이미지 붙여넣기**를 누릅니다.
2. 왼쪽 목록에서 카드를 선택하면 원본 카드와 인식 결과를 볼 수 있습니다.
3. **확실한 결과 일괄 확인**으로 점수가 높은 결과를 선택합니다. 이 점수는 정확도 확률이 아니므로 결과를 살펴보세요.
4. 나머지는 스타일 검색, 돌파 수, 다프네 상태를 수정하고 **확인하고 다음**을 누릅니다. **미확인** 값은 웹의 기존 값을 유지합니다.
5. **확인한 결과 복사** 후 스타일 체커의 **인식 결과 가져오기**에 붙여넣고 변경 내용을 확인하여 반영합니다. 결과를 파일로 보관하려면 **JSON 저장**을 사용합니다.

크롬, 엣지, 기본 브라우저 중 선택해 사이트를 열 수 있습니다. 브라우저 저장소를 직접 수정하지 않으며, 붙여넣기를 실행한 사이트와 브라우저 프로필에만 반영됩니다. 웹 가져오기 기능이 아직 배포되지 않았다면 개발 서버의 사이트에서 먼저 사용할 수 있습니다.

## 판독과 한계

- 완전하게 보이는 가로 카드만 처리합니다. 위아래가 잘린 카드는 다른 사진에서 읽습니다.
- 스타일 후보가 불확실하면 자동 선택하지 않습니다. 숫자나 아이콘 판독이 불확실하면 미확인으로 남깁니다.
- 확인하지 않은 행은 복사하지 않습니다. 중복 스타일의 돌파/다프네 값이 충돌하면 복사를 차단하므로 해당 행을 수정하거나 반영에서 제외하세요.
- 여러 장의 사진을 병합하지만 사진에 없는 스타일은 미보유로 바꾸지 않습니다.
- 사진은 서버에 보내거나 프로그램 폴더에 복사하지 않습니다. 클립보드 이미지는 실행 중 임시 폴더에 저장하며 종료 시 정리됩니다.
- 제공받은 모바일 목록 사진을 기준으로 개발했습니다. PC 실제 스크린샷과 다른 UI 배율, 언어, 낮은 화질은 추가 검증이 필요합니다. 현재 목록은 반복되는 카드가 최소 3열, 2행 이상 보여야 합니다.
- 스타일 그림은 기존 웹 카탈로그를 사용합니다. 신스타일이 추가되면 최신 카탈로그와 이미지로 다시 빌드해야 합니다. 자동 온라인 업데이트는 없습니다.

## 개발 검증

```powershell
.venv/Scripts/python -m unittest discover -s . -p "test_*.py"
.venv/Scripts/python evaluate.py --screenshots C:/Users/nanen/Downloads
.venv/Scripts/python ui_smoke.py
powershell -ExecutionPolicy Bypass -File build.ps1
```

`evaluate.py`는 제공받은 원본 사진이 있을 때 실행하는 회귀 검증입니다. 사진 자체는 저장소나 실행 파일에 포함하지 않습니다. `assets`에는 첫 번째 목록 사진에서 추출한 0~4 숫자와 다프네 아이콘의 작은 샘플만 들어 있습니다. `prepare_templates.py`는 해당 샘플을 재생성하는 개발 도구입니다.

2026-09-28 샘플 검증: 완전한 카드 56개의 스타일과 다프네 상태가 기대값과 일치했습니다. 돌파 수는 46개 판독, 10개 미확인이며 확정한 값의 오답은 없었습니다. 이 중 첫 사진 16개는 숫자 샘플 추출에 사용했으므로 독립 검증이 아닙니다. 나머지 40개 중 30개 숫자를 판독했습니다. 0.75/1.25배 리사이즈와 좌우 여백 추가는 카드 검출 수만 검증했으며, 실제 PC 화면 정확도를 보장하지 않습니다.
