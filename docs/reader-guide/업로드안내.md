# 게시판 업로드 자료

`게시글.md`가 게시판용 본문입니다. 실제 공개 다운로드 주소가 들어 있습니다. Markdown을 지원하지 않는 게시판에서는 본문 텍스트를 붙여넣고 아래 PNG를 해당 설명 사이에 첨부하세요.

| 순서 | 이미지 파일 | 넣을 위치 / 이미지 설명 |
| --- | --- | --- |
| 1 | images/01-download.png | 다운로드: Assets의 HBRStyleReader-Windows.zip 선택 |
| 2 | images/02-reader-start.png | 사진 추가: 앱 첫 화면 |
| 3 | images/03-reader-results.png | 결과 확인: 왼쪽 목록과 오른쪽 카드 비교 |
| 4 | images/04-reader-reviewed.png | 복사: 확인 완료 후 확인한 결과 복사 |
| 5 | images/05-web-paste.png | 붙여넣기: 웹의 인식 결과 가져오기 |
| 6 | images/06-web-preview.png | 변경 내용 확인: 반영 전후 값 비교 |
| 7 | images/07-web-applied.png | 완료: 4개 스타일 반영 메시지 |

모든 PNG는 실제 앱 또는 웹 화면입니다. 앱 결과는 제공된 모바일 스타일 목록 사진을 실제 분석해 만들었으며, 웹 예시는 그중 첫 네 스타일을 반영한 것입니다. 사용자 브라우저 대신 별도의 임시 브라우저 세션을 사용했습니다.

게임 원본 스크린샷 전체는 이 자료에 포함하지 않았습니다. `sample-result.json`은 캡처 재현용 예시이므로 이용자에게 본인 데이터로 붙여넣으라고 안내하지 마세요.

개발용 `local-reader/capture_guide.py`는 제공된 원본 사진과 Windows의 `pywin32` 패키지가 있을 때 앱 캡처를 재생성합니다. 일반 사용자 실행에는 이 패키지 설치가 필요하지 않습니다.
