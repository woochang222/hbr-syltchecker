# 헤번레 스타일 읽기 0.1.0 (시험 배포)

Windows용 로컬 스타일 인식 프로그램입니다. 스타일 목록 스크린샷에서 스타일, 한계 돌파, 다프네 상태를 읽고 스타일 체커에 붙여 넣을 결과를 만듭니다.

## 다운로드 및 실행

1. 아래 Assets에서 **HBRStyleReader-Windows.zip**을 받으세요. Source code는 실행 프로그램이 아닙니다.
2. ZIP 전체를 새 폴더에 압축 해제하세요.
3. **HBRStyleReader-Daphne.exe**를 실행하세요. 옆의 **_internal** 폴더를 지우거나 EXE만 따로 옮기지 마세요. Python 설치는 필요 없습니다.

## 사용 순서

사진 추가 → 인식 결과 확인 및 수정 → 확인하고 다음 → 확인한 결과 복사 → [스타일 체커](https://woochang222.github.io/hbr-syltchecker/)의 인식 결과 가져오기에 붙여넣기 → 변경 내용 확인 → 이 브라우저에 반영.

## 참고

- 인식은 PC에서 처리하며 사진을 서버로 전송하지 않습니다. 스타일 자료 업데이트만 인터넷 연결이 필요합니다.
- 현재 스타일 목록 화면만 지원합니다. 부대 편성 및 서포트 화면은 지원하지 않습니다.
- 잘린 카드와 불확실한 숫자는 인식되지 않을 수 있습니다. 결과를 확인하고 반영해주세요.
- 모바일 샘플 기준으로 검증한 초기 버전입니다. PC 화면과 다른 UI 배율은 추가 검증이 필요합니다.
- 데이터는 붙여넣은 브라우저 프로필에 저장됩니다. 다른 브라우저나 기기로 자동 동기화되지 않습니다.
- 코드 서명되지 않은 실행 파일입니다. Windows 경고가 나오면 공식 저장소의 배포 파일인지 확인하세요. 보안 프로그램을 끄지 마세요.
